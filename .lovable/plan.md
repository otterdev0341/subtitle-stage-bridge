# ปรับหน้าจัดเวที: กรอบจอ A/B, ลากมุมย่อขยาย, อัตราส่วนจอ, เทมเพลต และสไลด์พักจอ

## สิ่งที่ผู้ใช้จะได้
1. **กรอบบอกจอที่กำลังเลือก** – บนตัวอย่างเวที จอ A (สไลด์) และจอ B (คำแปล) มีกรอบสีต่างกันพร้อมป้ายชื่อ "A · สไลด์" / "B · คำแปล" จอที่เลือกอยู่จะมีกรอบหนาเรืองแสง คลิกที่จอไหนก็เลือกจอนั้น
2. **ลากย้ายและลากมุมเพื่อย่อขยาย** – จับกลางกรอบเพื่อลากย้าย จับจุดที่มุมทั้ง 4 เพื่อย่อ/ขยาย (กด Shift ค้างเพื่อคงสัดส่วน) แถบเลื่อนเดิมยังใช้ปรับละเอียดได้
3. **สลับหน้า-หลัง** – ปุ่ม "นำขึ้นหน้า / ส่งไปหลัง" และปุ่มลัด "สลับ A↔B" ให้จอคำแปลซ้อนบนหรือใต้สไลด์ได้
4. **กำหนดความละเอียด / อัตราส่วนเวที** – เลือก 16:9 (1920×1080), 16:10, 4:3, 21:9 หรือกำหนดเองกว้าง×สูง ตัวอย่างและจอฉายเต็มจอจะใช้สัดส่วนเดียวกัน (มีขอบดำถ้าจอจริงไม่ตรงสัดส่วน)
5. **บันทึกเทมเพลต** – ตั้งชื่อแล้วบันทึกการจัดวางทั้งหมด (ตำแหน่ง ขนาด ครอป ลำดับซ้อน อัตราส่วน ขนาดตัวอักษร) เลือกโหลด/ลบได้ มีเทมเพลตเริ่มต้นให้ 3 แบบ: "คำบรรยายแถบล่าง", "แบ่งครึ่งซ้าย-ขวา", "ภาพซ้อนมุมขวา"
6. **สไลด์พักจอของงาน (3 แบบ)** – ปุ่มสั่งขึ้นจอทันทีเมื่อจอพรีเซนต์หรือจอคำแปลกำลังแก้ไข:
   - "กรุณารอสักครู่" (โลโก้งาน + ข้อความ)
   - "หน้าชื่องาน" (ชื่องาน/ผู้บรรยาย)
   - "ขัดข้องทางเทคนิค"
   แก้ข้อความแต่ละแบบได้ เลือกแสดงทับทั้งเวที หรือแทนเฉพาะจอ A หรือจอ B และกด "กลับสู่การถ่ายทอด" เพื่อเอาออก

## หมายเหตุ
- เทมเพลตและข้อความสไลด์พักจอจะบันทึกไว้ในเบราว์เซอร์ของเครื่องควบคุม (ไม่ต้องล็อกอิน) ถ้าต้องการใช้ข้ามเครื่องค่อยย้ายไปเก็บในระบบภายหลัง
- สไลด์พักจอเป็นการออกแบบในแอป ไม่ใช่ไฟล์รูป จึงส่งไปจอฉายได้ทันทีผ่านช่องสัญญาณเดิม

## รายละเอียดทางเทคนิค
- ขยาย `BroadcastLayout` เป็นโครงสร้างสองเลเยอร์: `layers: { presentation, translation }` แต่ละชั้นมี x/y/width/height/crop/visible/zIndex, พร้อม `activeLayer`, `aspect: {w,h}`, `holdSlide: { id, target: "stage"|"presentation"|"translation" } | null`, `holdTexts` — ส่งผ่าน action `layout` เดิม
- คอมโพเนนต์ใหม่ `StageCanvas` (pointer events, ใช้หน่วย % ของเวที, handle 4 มุม), `AspectPicker`, `TemplateManager` (localStorage key `botnoi-relay-templates`), `HoldSlides`
- จอฉาย (`view=stage`) เรนเดอร์ทั้งสองเลเยอร์ตาม zIndex ภายในกล่อง aspect-ratio และแสดงสไลด์พักจอทับตาม target
- เพิ่ม unit test: การ clamp ขนาดเมื่อลากมุม, การสลับลำดับ, การบันทึก/โหลดเทมเพลต
